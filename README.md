# atashzadeh.github.io

A Github pages website based on [JekyllBear](https://github.com/knhash/jekyllBear).

To test locally, run `bundle exec jekyll serve`.

## Portfolio

This site features a portfolio page. Portfolio images are defined explicitly in portfolio.md.

## Recent works

This site features a recent works page. This displays all images by default, though certain images (wips, details, etc) can be explicitly excluded within the blog post itself.

## Atom feed

[Jekyll-feed](https://github.com/jekyll/jekyll-feed) is used to generate an Atom feed.
